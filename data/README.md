# Локальные документы

Помещайте PDF и UTF-8 TXT в `data/<тема>/`. Документы не включаются в Git.
Например, для темы `my_docs`: `python build_index.py --topic my_docs --prepare`.
Подготовка извлекает текст без API. Команда `--build` создаёт Google-индекс и требует ключ.

Проверенные банковские графики и контрольный набор вопросов зависят от исходного
корпуса «Банкинг», который не распространяется с кодом. Без него два интеграционных
теста таблиц пропускаются; остальные тесты работают с временными данными.
