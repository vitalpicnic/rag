# Разрешение передачи данных внешней модели

Этап 6 добавляет `PolicyStore`, `PrivacyGate` и подключение к `build_history_chain`.
По умолчанию тема запрещает внешнюю генерацию. Разрешение требует одновременно
`external_generation: allow` у темы и точного совпадения provider/endpoint.
Запрет `sources.<source_id>.external_generation: deny` сильнее разрешения темы.
При разрешённой теме источники без отдельного правила наследуют её разрешение.
LOCAL запрещает все внешние вызовы через этот механизм.

## Файл оператора

Скопируйте [пример](../deploy/privacy-policy.example.json) в `policies/external.json`
(каталог исключён из Git). По умолчанию пример ничего не разрешает. Для разрешённой
темы оператор меняет `deny` на `allow`, задаёт конечную точку и при необходимости
запреты отдельных источников:

```json
"sources": {
  "SOURCE_ID_FROM_CHUNK_METADATA": {"external_generation": "deny"}
}
```

Используйте `source_id` из метаданных v2 фрагментов, а не имя файла. Политика хранится
отдельно от реестра достоверности источников, PDF, embeddings и FAISS. Её изменение
не требует переиндексации. `schema_version: 1` задаёт формат; SHA256 содержимого
служит версией политики для запроса и не является подписью доверенного оператора.

Файл должен быть доступен на запись только оператору, сервису — на чтение.
Обновляйте его атомарной заменой в том же каталоге (`os.replace` после записи
и fsync временного файла; на Linux также fsync каталога). Ошибка чтения, отсутствие,
некорректный JSON, прямая символическая ссылка или размер больше 1 MiB запрещают
передачу; последнее разрешение не используется как запасной вариант.

## Подключение в коде

```python
from rag.privacy import PolicyStore, PrivacyGate

gate = PrivacyGate(
    PolicyStore("policies/external.json"),
    topic="default",
    provider="gemini",
    endpoint="https://generativelanguage.googleapis.com",
    profile="HYBRID",
)
# Передать privacy_gate=gate при вызове build_history_chain(...).
# Для будущего внешнего подсчёта токенов:
# lease = gate.authorize_documents(documents)
# count = gate.call(lease, provider.count_tokens, messages)
```

Endpoint выбирает доверенная конфигурация сервера, а не пользовательский запрос.
Он должен совпадать с адресом фактического клиента. Разрешены только HTTPS URL без
credentials, query и fragment; путь учитывается, trailing slash нормализуется.
Ключ провайдера не входит в политику. Механизм проверяет разрешение, но сам не
создаёт HTTP-клиент и не контролирует redirects/proxy стороннего SDK.

Lease проверяется перед вызовом, после него и перед возвратом текста ответа.
Изменение любой части политики инвалидирует текущий lease; новый запрос получает
новую версию. Переданные до отзыва данные невозможно вернуть: результат такого
вызова отбрасывается при обнаружении изменения. Изменение и обратное восстановление
файла между двумя проверками не обнаруживаются. Это проверки границ вызовов,
а не атомарная отмена уже отправленного сетевого запроса.

## Текущее подключение и ограничения

- `build_history_chain(..., privacy_gate=gate)` защищает генерацию. При
  `RAG_ENV=production` создание цепочки без gate запрещено. Старый engine пока
  не передаёт gate, поэтому его production-запуск блокируется. Development сохраняет
  прежний путь для совместимости; это не режим защищённой эксплуатации.
- Для защищённой цепочки требуется локальный retrieval: guard генерации не
  защищает отдельный внешний embedding-запрос. Сборка нового runtime — следующий этап.
- История старого диалога не содержит происхождения данных. Защищённая внешняя
  генерация отклоняет непустую историю; начните новую сессию. Передача истории
  возобновится после реализации проверки её источников.
- Внешний countTokens пока не реализован: проверен общий guard, через который он
  должен вызываться на этапе token-aware packing. OpenAI-compatible указан как
  допустимый тип политики, его адаптер ещё не реализован.
- Проверки не отправляют данные в API; тесты используют подставную модель. Реальная
  Ollama/Gemini и Linux-приёмка остаются отдельными проверками.

Проверка: `python -m unittest discover -s tests -p test_privacy.py -q`.
