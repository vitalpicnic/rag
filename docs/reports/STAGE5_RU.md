# Этап 5: проверенные таблицы и локальные графики

Первое покрытие: оценки активов пяти банков (Сбербанк, ВТБ, Альфа-Банк, Россельхозбанк, Т-Банк) на 01.01.2025 и 01.12.2025 по РИА Рейтинг, страница 1. Десять наблюдений; два среза, не итог года.

`rag_tables.py` хранит проверенные полные строки PDF и SHA-256 источника. При сборке проверяются хеш, заголовки дат/единиц и строки. SQLite содержит десятичные значения, организацию, дату, единицу, показатель, путь, страницу, хеш и текст подтверждения. При чтении повторно проверяются источник и соответствие записей проверенному набору. Подмена таблицы или PDF приводит к отказу.

`build_tables.py` атомарно создаёт `prepared_tables/banking.sqlite`. Подготовленная база исключена из git и воспроизводится без ключей. Новые источники требуют явной проверки и расширения набора; автоматического импорта произвольных таблиц нет.

Режим «График» предлагает пять банков и сравнение всех пяти. PNG строится matplotlib Agg локально в памяти через существующую очередь, без LLM и embeddings. Отправляется с датами, единицами и кнопкой скачивания PDF. Неподдерживаемые запросы получают список доступных вариантов. RAG-индекс и Google-ключ для графиков не нужны; для настоящей Telegram-отправки нужен токен.

Пример: [stage5_assets.png](../../reports/stage5_assets.png). Изображение просмотрено: подписи читаются, значения не перекрываются, источник и страница указаны, ось начинается с нуля.
