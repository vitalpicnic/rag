# План реализации аналитических режимов и PPTX

**Основание:** пользователь разрешил реализацию пунктов 1–3; сбор Telegram исключён.
**Архитектура:** общий конвейер сохраняет обратную совместимость text/overview.
Новые режимы executive/expert меняют выбор контекста и инструкции модели.
Проверенная вручную классификация источника привязана к SHA-256 файла в
data/<topic>/sources.json и применяется при чтении, без пересчёта embeddings.
Экспорт локальный, без повторного вызова модели, через python-pptx.

- [x] rag/analysis.py, rag/evidence.py, rag/pipeline.py, rag/engine.py, rag/index.py:
  тесты режимов, сохранения альтернативных источников, политики сопоставимости;
  расширить поиск и бюджет ответа для двух ролей.
- [x] rag/sources.py: тесты реестра, неизвестных источников, неверного хеша и URL;
  добавить явный статус official_report/analysis/unknown и ссылки.
- [x] rag/slides.py: тесты редактируемого слайда, точности копирования чисел,
  заметок, переполнения и отказа при недостатке подтверждений; добавить зависимость.
- [x] bot.py, app.py, main.py: выбор роли и экспорт ответа; тесты изоляции
  пользователей, очистки экспорта и отсутствия повторного вызова модели.
- [x] Проверить весь офлайн-набор, синтаксис и diff; обновить README.

Ограничения: статус official_report задаёт оператор, не LLM; структурные ссылки
не доказывают достоверность ответа. Слайд не вводит новых чисел; длинный ответ
сохраняется в заметках, сокращение явно отмечается. Качество интерпретации
противоречий моделью требует отдельной проверки с реальным API.

Проверено: `python -m unittest discover -s tests` — 78 тестов успешно;
`py_compile` изменённых модулей и `git diff --check` — без ошибок.
PPTX проверен программно повторным открытием, проверкой редактируемой таблицы,
текста заметок, чисел, ссылок и геометрических границ объектов; визуальная
проверка в PowerPoint не выполнялась. Веб-интерфейс проверен синтаксически,
Telegram — локальными тестами обработчиков, без обращения к Telegram API.
